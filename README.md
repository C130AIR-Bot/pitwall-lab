# Pitwall Lab

Pitwall Lab is a standalone browser-based race weekend toolkit. It includes:

- An editable Monte Carlo tyre strategy simulator with one-stop and two-stop plans, tyre wear, weather, safety-car windows, pit loss, and traffic risk.
- A two-driver championship scenario model with configurable points, expected finishes, and per-event result variance.
- A local race-weekend planner with a countdown, persistent checklist, and .ics calendar export.

The page uses vanilla HTML, CSS, and JavaScript. No account, build step, server, or external data API is required. Planner data stays in the current browser. Strategy and points outputs are illustrative models based on user inputs, not official telemetry or predictions.

## Run locally

Open index.html in a modern browser.

## Publish

The repository root contains the app. Enable GitHub Pages from the main branch root to publish it at https://c130air-bot.github.io/pitwall-lab/.
